# SmartTeam AI — Unified Machine Learning Microservice

This folder contains the **unified Machine Learning microservice** for the Smart Team Formation system. It consolidates all ML models and algorithms into a single service running on **Port 8000**.

---

## 🚀 Quick Start (Running the ML Service)

Open PowerShell in this directory:

```powershell
# 1. Navigate to the ml folder
cd ml

# 2. Activate virtual environment
.\.venv\Scripts\activate

# 3. (Optional) Re-train all models
python train_models.py

# 4. Start the unified FastAPI microservice
uvicorn main:app --reload --port 8000
```

* **Microservice Root:** `http://127.0.0.1:8000/`
* **Health Check:** `http://127.0.0.1:8000/health`
* **Interactive API Docs (Swagger UI):** `http://127.0.0.1:8000/docs`

---

## 📡 API Endpoints

### 1. `POST /predict` (Primary Endpoint used by Java Backend)
Calculates teammate compatibility probability using the **Soft Voting Ensemble Classifier**.

* **Input JSON:**
  ```json
  {
    "skill_match": 85.0,
    "interest_match": 100.0,
    "availability": 100.0,
    "experience": 80.0,
    "communication": 70.0,
    "reliability": 70.0
  }
  ```
* **Output JSON:**
  ```json
  {
    "label": "COMPATIBLE",
    "probability": 0.8417,
    "percentage": 84.17
  }
  ```

---

### 2. `POST /cluster` (K-Means Student Segmentation)
Categorizes candidate profiles into $k=4$ student archetypes.

* **Input JSON:**
  ```json
  {
    "skill_match": 85.0,
    "interest_match": 100.0,
    "availability": 100.0,
    "experience": 80.0
  }
  ```
* **Output JSON:**
  ```json
  {
    "cluster": 0,
    "archetype": "High-Skill Specialist",
    "meaning": "Student profile segment generated by K-Means"
  }
  ```

---

### 3. `POST /predict-match` (TF-IDF & Cosine Similarity)
Computes textual relevance using n-gram TF-IDF and cosine similarity.

* **Input JSON:**
  ```json
  {
    "project_name": "Smart Attendance System",
    "required_skills": "Java, Python, Machine Learning",
    "project_availability": "Monday, Saturday",
    "candidate_skills": "Java, Python, Spring Boot",
    "candidate_interests": "Machine Learning, Web Development",
    "candidate_availability": "Monday, Saturday",
    "candidate_experience": "intermediate"
  }
  ```
